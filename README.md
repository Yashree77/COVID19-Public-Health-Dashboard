# COVID-19 Public Health Dashboard

A Streamlit dashboard for analyzing COVID-19 public health trends using data from Our World in Data.

## Features

- Country comparison of COVID-19 total cases
- Interactive date-range slider
- COVID-19 choropleth map
- Correlation heatmap
- Interactive charts using Plotly

## Data Source

Our World in Data — COVID-19 Dataset

The dashboard loads the latest data directly from the Our World in Data catalog.

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## How to Run

Install the required libraries:


```bash
pip install -r requirements.txt
streamlit run app.py
